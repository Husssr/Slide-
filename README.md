# สไลด์ ทางสายกลางกับความพอประมาณ (กลุ่ม 1 ม.5/5)

Static site — ไม่ต้อง build

## Deploy บน Render
1. push โฟลเดอร์นี้ขึ้น GitHub
2. Render → New → Static Site → เลือก repo
3. Build Command: (เว้นว่าง) · Publish Directory: `.`
   (หรือใช้ Blueprint จาก `render.yaml`)
